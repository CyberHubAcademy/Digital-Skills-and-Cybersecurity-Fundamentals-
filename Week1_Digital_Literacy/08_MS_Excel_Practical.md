## 📘 What is Microsoft Excel?
Microsoft Excel is a **spreadsheet application** used to organize, analyze, and visualize data.  
It is widely used in business, finance, research, and education.

---

## 🖼️ Excel Interface Overview
- **Workbook**: A file containing one or more worksheets.  
- **Worksheet**: A single spreadsheet page.  
- **Cells**: Intersection of rows and columns (e.g., A1, B2).  
- **Ribbon**: Tabs like Home, Insert, Formulas, Data, Review, View.  
- **Formula Bar**: Displays or edits the contents of the selected cell.  
- **Status Bar**: Shows sum, average, and other quick calculations.  

---

## ✍️ Basic Operations
- **Entering data**: Click a cell and type.  
- **Editing data**: Double‑click a cell or edit in the formula bar.  
- **Saving workbook**: File → Save As → Choose location → Enter file name.  
- **Shortcut**: Ctrl + S.  

---

## 🔢 Formulas and Functions
- **Formulas**: Begin with `=`.  
  - Example: `=A1+B1` adds values in cells A1 and B1.  
- **Basic Functions**:  
  - SUM: `=SUM(A1:A5)`  
  - AVERAGE: `=AVERAGE(B1:B10)`  
  - MAX: `=MAX(C1:C10)`  
  - MIN: `=MIN(C1:C10)`  

---

## 🎨 Formatting Worksheets
- **Adjust column width/row height**: Drag borders.  
- **Bold, Italics, Underline**: Same as Word.  
- **Cell borders**: Add lines around cells.  
- **Cell shading**: Fill cells with color.  
- **Number formats**: Currency, Percentage, Date.  

---

## 📊 Charts and Graphs
1. Select data range.  
2. Click Insert → Choose chart type (Column, Line, Pie).  
3. Customize chart with titles and labels.  

---

## 🧪 Practical Exercise
Students should:
1. Create a worksheet titled *SIWES Attendance*.  
2. Enter names of 5 students in column A.  
3. Enter attendance for 5 days in columns B–F (use 1 for present, 0 for absent).  
4. Use `=SUM()` to calculate total attendance for each student.  
5. Use `=AVERAGE()` to calculate average attendance.  
6. Create a bar chart showing attendance totals.  
7. Save the workbook as `Week1_Attendance.xlsx`.
