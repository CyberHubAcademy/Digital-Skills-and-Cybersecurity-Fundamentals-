## 📘 What is Microsoft Word?
Microsoft Word is a **word processing application** used to create, edit, format, and print documents.  
It is part of the Microsoft Office Suite and is widely used in business, education, and personal settings.

---

## 🖼️ Word Interface Overview
- **Title Bar**: Displays the document name and application title.  
- **Ribbon**: Contains tabs (Home, Insert, Design, Layout, References, Review, View).  
- **Quick Access Toolbar**: Provides shortcuts for Save, Undo, Redo.  
- **Document Area**: The workspace where text and objects are entered.  
- **Status Bar**: Shows page number, word count, language, zoom level.  

---

## ✍️ Basic Document Operations
- **Create a new document**: File → New → Blank Document.  
- **Save a document**: File → Save As → Choose location → Enter file name.  
- **Open an existing document**: File → Open → Browse → Select file.  
- **Close a document**: File → Close.  

---

## 🔤 Editing and Formatting
- **Typing and inserting text**: Place cursor and type.  
- **Deleting text**: Use Backspace or Delete.  
- **Replacing text**: Select and type new content.  
- **Cut, Copy, Paste**:  
  - Cut: Ctrl + X  
  - Copy: Ctrl + C  
  - Paste: Ctrl + V  
- **Formatting text**:  
  - Bold (Ctrl + B)  
  - Italics (Ctrl + I)  
  - Underline (Ctrl + U)  
  - Font size and style changes  

---

## 📑 Paragraph Formatting
- **Alignment**: Left, Center, Right, Justify.  
- **Line spacing**: Single, 1.5, Double.  
- **Lists**: Bulleted and numbered.  

---

## 📄 Page Setup
- **Margins**: Adjust spacing around text.  
- **Orientation**: Portrait or Landscape.  
- **Page size**: A4, Letter, etc.  

---

## 🖋️ Enhancing Documents
- **Insert tables**: Organize data.  
- **Insert pictures**: Add visuals.  
- **Headers and footers**: Add consistent info at top/bottom of pages.  
- **Page numbers**: Number pages automatically.  

---

## 🖨️ Printing
- File → Print → Select printer → Adjust settings → Print.  
- **Print Preview**: Check layout before printing.
