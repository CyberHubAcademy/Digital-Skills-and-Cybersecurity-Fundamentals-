## 📘 What is Microsoft PowerPoint?
Microsoft PowerPoint is a **presentation application** used to create slideshows for teaching, business, and communication.  
It allows users to combine text, graphics, and multimedia into engaging presentations.

---

## 🖼️ PowerPoint Interface Overview
- **Title Bar**: Displays presentation name.  
- **Ribbon**: Tabs like Home, Insert, Design, Transitions, Animations, Slide Show, Review, View.  
- **Slides Pane**: Shows thumbnails of slides.  
- **Slide Area**: Workspace for designing the current slide.  
- **Notes Pane**: Add speaker notes.  
- **Status Bar**: Displays slide number and view options.  

---

## ✍️ Creating and Saving Presentations
- **New Presentation**: File → New → Blank Presentation.  
- **Saving**: File → Save As → Choose location → Enter file name.  
- **Shortcut**: Ctrl + S.  
- **Opening**: File → Open → Browse → Select presentation.  

---

## 📑 Working with Slides
- **Add a new slide**: Home → New Slide.  
- **Change slide layout**: Home → Layout → Choose layout (Title, Content, Two Content, etc.).  
- **Delete a slide**: Right‑click slide thumbnail → Delete Slide.  
- **Reorder slides**: Drag thumbnails in the Slides Pane.  

---

## 🎨 Designing Slides
- **Themes**: Design → Choose theme.  
- **Background styles**: Design → Format Background.  
- **Colors and fonts**: Customize theme colors and fonts.  

---

## 📊 Inserting Content
- **Text boxes**: Insert → Text Box.  
- **Pictures**: Insert → Pictures → Select image.  
- **Tables**: Insert → Table → Choose rows and columns.  
- **Charts**: Insert → Chart → Select type (Column, Line, Pie).  
- **SmartArt**: Insert → SmartArt → Choose diagram style.  

---

## 🎬 Transitions and Animations
- **Transitions**: Apply effects between slides (Fade, Wipe, Push).  
- **Animations**: Apply effects to objects (Appear, Fly In, Zoom).  
- **Preview**: Play transition/animation to see effect.  

---

## 📽️ Slide Show
- **Start slideshow**: Slide Show → From Beginning (F5).  
- **From current slide**: Shift + F5.  
- **Presenter view**: Shows notes and upcoming slides.
