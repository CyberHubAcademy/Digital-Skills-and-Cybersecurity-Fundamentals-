## 🎯 Learning Objectives
By the end of this session, students should be able to:
- Create professional documents in Microsoft Word.
- Format text and paragraphs appropriately.
- Insert tables, images, headers, and footers.
- Save, open, and print documents.
- Apply shortcuts for efficiency.

---

## 🖥️ Starting Microsoft Word
### Methods
1. Click the **Start Menu**, search for *Microsoft Word*, and open it.  
2. Double‑click the Word icon on the desktop.  
3. Open an existing Word document.  

---

## 🖼️ Components of the Word Window
- **Title Bar**: Shows document name and application title.  
- **Quick Access Toolbar**: Contains Save, Undo, Redo.  
- **Ribbon**: Tabs like Home, Insert, Design, Layout, References, Review, View.  
- **Document Area**: Workspace for typing and editing.  
- **Status Bar**: Displays page number, word count, language, zoom level.  

---

## ✍️ Creating and Saving Documents
- **New Document**: File → New → Blank Document.  
- **Saving**: File → Save As → Choose location → Enter file name.  
- **Shortcut**: Ctrl + S.  
- **Opening**: File → Open → Browse → Select document.  

---

## 🔤 Editing Text
- **Insert text**: Type at cursor position.  
- **Delete text**: Backspace or Delete key.  
- **Replace text**: Select and type new content.  
- **Move text**: Cut (Ctrl+X) and Paste (Ctrl+V).  
- **Select all**: Ctrl + A.  

---

## 🎨 Formatting Text
- **Font styles**: Times New Roman, Arial, Calibri.  
- **Font sizes**: Body (12 pt), Heading (14–16 pt), Title (16–18 pt).  
- **Bold**: Ctrl + B  
- **Italics**: Ctrl + I  
- **Underline**: Ctrl + U  

---

## 📑 Paragraph Formatting
- **Alignment**:  
  - Left (Ctrl + L)  
  - Center (Ctrl + E)  
  - Right (Ctrl + R)  
  - Justify (Ctrl + J)  
- **Line spacing**: Single, 1.5, Double.  
- **Lists**:  
  - Bulleted (• Mediation, Negotiation, Arbitration)  
  - Numbered (1. Identify conflict, 2. Analyze causes, 3. Develop solutions)  

---

## 📄 Page Layout
- **Margins**: Common setting = 1 inch all sides.  
- **Orientation**: Portrait (vertical) or Landscape (horizontal).  
- **Page size**: A4 or Letter.  

---

## 📊 Tables and Pictures
### Insert Table
1. Click Insert → Table.  
2. Choose rows and columns.  
3. Fill with data.  

### Insert Picture
1. Click Insert → Pictures.  
2. Select image file.  
3. Click Insert.  

---

## 🖋️ Headers, Footers, and Page Numbers
- **Headers**: Appear at top of each page (e.g., organization name).  
- **Footers**: Appear at bottom (e.g., date, document title).  
- **Page Numbers**: Insert → Page Number → Choose location.  

---

## 🖨️ Printing Documents
- File → Print → Choose printer → Set copies → Print.  
- **Print Preview**: Review document before printing.  

---
