## 🖥️ Computer Hardware
Hardware refers to the physical components of a computer system that can be seen and touched.

### Essential Components
- **Motherboard**: The main circuit board connecting all components. Includes CPU socket, RAM slots, expansion slots, SATA connectors, power connectors, USB headers, CMOS battery.
- **Central Processing Unit (CPU)**: Executes instructions and performs calculations.
- **Random Access Memory (RAM)**: Temporary working memory for active processes. Volatile — contents are lost when power is removed.
- **Storage Devices**: HDD, SSD, USB flash drives, memory cards.
- **Power Supply Unit (PSU)**: Provides electrical power to the system.
- **Cooling System**: Fans or heat sinks to prevent overheating.
- **Input Devices**: Keyboard, mouse, scanner, microphone, webcam.
- **Output Devices**: Monitor, printer, speakers, projector.
- **Expansion Devices**: Network interface cards, graphics cards.

---

## 🔧 CMOS Battery
- Provides power to the motherboard’s BIOS/UEFI settings.
- Maintains system time and configuration when the computer is powered off.

---

## 💾 Software
Software refers to instructions that tell the hardware what to do.

### Types
- **System Software**: Operating systems (Windows, Linux, macOS), device drivers, utilities.
- **Application Software**: Word processors, spreadsheets, browsers, media players.

---

## ⚙️ Operating Systems
- **Windows 11**: Graphical interface, widely used for business and general computing.
- **Ubuntu Linux**: Open-source, supports graphical and command-line interfaces, widely used in servers, development, and cybersecurity.

## 🧪 Practical Demonstration
During the Practical session the students should be able to 
1. Show the **motherboard** and point out CPU socket, RAM slots, expansion slots, CMOS battery.    
2. Show input/output devices and explain their roles.  
3. Assemble and disassemble a desktop computer safely.  
4. Boot into BIOS/UEFI to show CMOS battery function.  
5. Compare Windows and Ubuntu interfaces.  
6. Create, copy, move, rename, and delete files/folders.
