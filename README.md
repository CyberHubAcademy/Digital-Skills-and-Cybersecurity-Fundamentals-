Delivered by ALGURAWY CYBERHUB SOLUTIONS LTD  
Under ALGURAWY CYBERHUB ACADEMY  

## 📘 Overview
This repository contains lecture notes and beginner-friendly labs introducing **digital literacy, professional development, and cybersecurity fundamentals**.  
The content is arranged in chronological order, starting from **basic computer and workplace skills** and progressing to **network analysis, scripting, and vulnerability awareness**.  

---

## 📚 Learning Path

### Week 1 – Digital Literacy & Professional Development
- Computer hardware components and functions  
- System software vs application software  
- File and data management  
- Microsoft Office (Word, Excel, PowerPoint)  
- Google Workspace collaboration tools  
- Internet fundamentals and professional email writing  
- Workplace ethics and responsible technology use  

### Week 2 – Linux & Networking Basics
- Linux command fundamentals (navigation, file operations)  
- User and permission management  
- IP addressing and subnetting  
- Basic network connectivity (Ping)  

### Week 3 – Networking & Security Tools
- OSI Model in practice  
- Port scanning with Nmap  
- Service enumeration  
- Network traffic analysis with Wireshark  

### Week 4 – Automation & Security Awareness
- Bash scripting basics  
- Vulnerability awareness and defensive security concepts
